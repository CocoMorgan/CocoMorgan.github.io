I created a C program called Sweater Weather for this assignment that reccomends different types of clothing based on different temperatures. I started the program by using an integer variables I called temperature and had the program output a message describing the appropriate clothing depending on the value of temperature. This assignment was awesome because I got to get practice using coniditonal statements, where I used if, else if, and else statements to control what type of clothing and weather message was printed. I used different temperature ranges that corresponded to extreme cold, freezing, cold, cool, warm, hot, and extreme heat conditions.

Here is a screenshot of my VS Code Debug Console output!

![screenshot](https://CocoMorgan.github.io/assets/img/Sweater-Weather-Debug-Console.jpeg)

A tip I would give my past self for completing this deliverable would be to test the program frequently when writing it instead of waiting until the end. Even though Professor Howley advised that we do this in class, I did not follow her advice and, because of that, this assignment took a lot longer because by the time I ran the program, I had a ton of error messages. So, I think that testing the programming frequently is an extremely helpful top because a) it helps you catch mistakes early and b) can also help correct any overlaps or gaps you might have between temperature ranges/conditions.
