For the Circuit Plushy project, I was able to design and create a salmon-colored, light up plushy using conductive thread and simple circuits for the first time! I was able to make the plushy light up with three LEDs by using a slide switch that is turned on and a button that is pressed.

I started this project by firs tmaking a paper prototype in order to plan the circuit layout. Then, I tested this paper prototype using alligrator clips, and once it was confirmed that everything worked, I sewed the different componenents into the felt. I used a running stitch for the electrical connections (conductive thread) and whip switches to assemble the plushy (non-conductive thread), which gave me more practice in doing neat stitching and new practice in learning how to secure connections in order for circuits to properly work. Overall, i would say this project helped me to understand circuits in a hands-on way and get more practice with sewing and design.

A tip I would give my past self for completing this assignment is that when working with conductive thread, it can easily get tangled and break, so my advice is to work slowly. Be careful, especially when working with long lengths of this tread, when pulling the thread through pieces of fabric because oftentimes the thread knotted and then when trying to unknot the thread, it would break. Have patience, stay calm, and move slowly becaues that will actually save you time in the long-run.
