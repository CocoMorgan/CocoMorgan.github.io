For the Odd Menu assignment, I wrote a C-program that creates a made-up restuarant with two different menus: a secret one and a regular one. In this assignment, I used the variable numberChoice and the modular operator to determine if a number is even or odd. When a value in numberChoice was even, the user would get the regular menu, but if the value in numberChoice was odd, the user would get the secret menu. 

For this assignment and for each menu, I used nested if, else if, else statements to determine specifically what meal a user will get based on the variable mealOption. For each menu, I made it so there are three different meal options, and I also was able to account for if there is a case in which a user enters an invalid meal option.

A tip I would give my past self in completing this assignment would be that if I'm ever stuck and don't know where to start, a helpful thing to do is to go back and look at our past class slides and examples. For this project, I wasn't exactly sure initially on how to set up the regular and secret menus in the program, but after quite a bit of contemplation and trying to figure out what I should do, it finally dawned on me that I should review the slides. By doing this, I was reminded that I could use the modular operator to check if a number is odd or even! Once I was able to figure that out, the assignment because much easier.
